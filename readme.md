# FreeDomain.meme 

A free Subdomain hosting service.

# How to run:

1. Clone the repo

2. Edit your example.env and rename to .env

3. start it with python main.py (and install all modules)


# Features

* 1 free subdomain per user

* Tries to scrape existing subdomains every 6 hours, to disable any phishing, etc sites

* Has admin tools on Discord + Logging

* Also catshes all errors and sends them to me.
