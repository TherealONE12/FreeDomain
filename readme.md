# welcome to Freedomain.meme!

## Freedomain.meme is an free Subdomain Hosting service you can use to get easier - readable domains to your services and it has full On Potection - Systems against Bad domainnames, and bad websietes (WIP)

It is build on top of Flask, and it has an SQLITE DB for Users, subdomains, secrets etc. All Password of the users are generated by the server, to improve security and the OTP Passcodes also work great!
