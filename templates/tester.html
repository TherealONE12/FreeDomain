There are 2 Types of IPs



Indirect IPs:



Mouch of the internet runs on Indirect IPs. These are Ips where many servers are using the same ip, and the name of the Domain says where to go



Freedomain.meme is NOT Build for these types of ips. (For example, all of Cloudflare ips are these)



2. Direct IPs



These are IPs where only 1 server goes to that IP and not more



A large amount of Homeservers and selfhosted sites run via these.



Freedomain.meme is Build for THIS type of site.
